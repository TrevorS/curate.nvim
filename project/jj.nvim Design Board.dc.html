jj deleted the index, so ~60% of magit/fugitive solves a problem that's gone. Spend that budget on jj's own primitives instead — be its diff-editor, its op-log time machine, its revset IDE.

We put the board in front of five people who'd actually use (or sell) it.

Each reviews the mockups in character, three times. Every round we synthesize the conflicts and ship changes back into the board — the changelog below is styled as a jj op-log, because of course it is. Edits that landed on the frames above are tagged R1 / R2 / R3 (name) inline.

the workflow · enumerated · critiquable

Every gesture, broken into a step you can argue with.

Five daily loops, 23 atomic steps. Each step has the same six-field anatomy — and a seeded open question so the next crit pass has something specific to fight about. Reference any step by id (B2, C4) the way you reference frames.

the five sequencing rules
1 · Derisk the data layer before any UI — change-id anchoring is load-bearing.
2 · Differentiate early — the diff-editor is P2, not a late polish item.

5 · Defer the power surface to reserved keys; ship the spine (P0→P3) first — it's already a daily driver nobody else offers.
